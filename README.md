# Dashboard-de-Controle-de-Caixa-e-Faturamento-Di-rio-Google-Sheets-

Necessidade de centralizar o controle financeiro operacional de um negócio, automatizando o cálculo de entradas, saídas e saldo, além de gerar visualizações para acompanhamento de tendências.

3.Tecnologias e Funções:

A Solução Desenvolvida.Google Planilhas: Utilização de funções lógicas e de agregação (SOMA) para consolidação dinâmica de dados.Engenharia de Dados Básica: Limpeza, padronização e estruturação de colunas de data, descrição, categorias e valores monetários.Visualização de Dados: Construção de gráficos de tendências temporais com agrupamento automático (Agregar) para análise visual de picos de faturamento.

4.Valor Gerado:

Principais Resultados.Automatização completa do cálculo de saldo e fechamento de caixa, eliminando erros manuais.Criação de um painel visual dinâmico para acompanhamento diário da saúde financeira do negócio.
